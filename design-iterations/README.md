# Локальные варианты

`merch-shirt-3d-v1.js` — сохранённый исходный вариант 3D-футболки.

`merch-shirt-3d-v2.js` — вариант с более мягким силуэтом, полыми рукавами и небольшими складками.

Оба варианта отключены от сайта: на главной сейчас используется плоская фотография с лёгкой CSS-анимацией. Фотографии обратной стороны для восстановления 3D сохранены в `dist/images/merch/dom/*/back-preview.png`.
