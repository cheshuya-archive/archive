# Чешуя — изображения

## Оптимизация фото

1. Положите оригиналы в `images-source`. Вложенные папки сохранятся в итоговой структуре.
2. Запустите `npm run images:optimize`.
3. Готовые версии появятся в `public/images`: для каждого фото будут файлы `-600.webp`, `-1200.webp` и `-2000.webp` с качеством 82. Для текущей статической версии сайта они автоматически копируются также в `dist/images`.
4. Добавьте в Git только `public/images`, не `images-source`.

Скрипт хранит контрольные суммы в `public/images/.image-manifest.json`, поэтому неизменённые исходники повторно не кодируются. Маленькие фотографии не увеличиваются: варианты, превышающие размер оригинала, сохраняют его исходный размер.

Next.js использует статический экспорт и отключённый серверный оптимизатор изображений — это необходимо для GitHub Pages. Для сборки с путём репозитория в PowerShell используйте `$env:NEXT_PUBLIC_GITHUB_PAGES='true'; npm run build`.
