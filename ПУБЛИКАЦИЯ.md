# Как публиковать сайт самостоятельно

1. Создайте **пустой публичный** репозиторий на GitHub. При создании не добавляйте README, `.gitignore` или лицензию — всё это уже есть в проекте.
2. В настройках нового репозитория откройте **Settings → Pages** и в разделе **Build and deployment** выберите **Source: GitHub Actions**. Если пункт ещё недоступен, сделайте первый запуск скрипта, затем вернитесь к этой настройке.
3. В этой папке дважды щёлкните `publish-site.cmd`. В первый раз вставьте HTTPS-ссылку на **новый** репозиторий, например `https://github.com/ваше-имя/cheshuya`. Проверьте показанный список файлов и введите `PUBLISH`.
4. Дождитесь завершения задачи **Publish site** во вкладке **Actions** нового репозитория. Если Pages пришлось включить после первой отправки, нажмите **Run workflow** для этой задачи или отправьте следующее обновление.
5. Для следующих обновлений снова запускайте `publish-site.cmd`: адрес нового репозитория запоминается. Старый `origin` не изменяется. Скрипт **не делает принудительную отправку** и не удаляет файлы.

Публикуется готовый сайт из папки `dist`. Оригиналы в `images-source` остаются только на этом компьютере; перед публикацией новых фотографий их нужно оптимизировать командой `npm run images:optimize`. После этого запустите `publish-site.cmd`.

Если сайт не обновился, смотрите ошибку во вкладке **Actions**. Если отправка отклонена, проверьте, что вы вошли в новый аккаунт GitHub и создали именно пустой репозиторий. Не используйте принудительную отправку (`--force`).
